How it works

What each score means

Maturation: pan-neuronal synaptic/cytoskeletal maturation genes, kept separate from dopaminergic genes. DA identity: midbrain floor-plate TFs + dopamine synthesis/handling. Fidelity subtracts non-midbrain (forebrain/hindbrain) identity. Stress: glycolysis and ER-stress programs typical of stressed organoid cells (Bhaduri 2020; Gruffi, Vértesy 2022). Hypoxia: HIF targets, with glycolytic enzymes excluded so hypoxia is not double-counted. All sets are non-overlapping and frozen before analysing the ISS data.

Scoring: within each sample, each program gene is ranked against background genes (genes in no program); a program's score is the mean of those ranks − 0.5. Ranking against background only means one program rising cannot drag the others down. Scores ignore library size and work on bulk RNA-seq and single-cell pseudobulk alike.

Verdict rules (pre-registered)

Promising maturation: maturation up (g ≥ 0.5), identity/fidelity not down, no stress program up. Mixed state: maturation up together with a stress/hypoxia program. Dysregulated: maturation up but DA identity or fidelity down (g ≤ −0.5). Insufficient evidence: no robust maturation increase. Every call also requires FDR q < 0.05 (within-stratum permutation test) and the same direction in every cell line; the Python package additionally requires a bootstrap CI excluding 0.
