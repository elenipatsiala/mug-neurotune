How it works

What each score means

Age clock ✓ (the maturation axis): 50 genes that rise and 50 that fall as human fetal midbrain neurons age (6–11.5 weeks post-conception; GSE192405), learned on fetal tissue only and then tested blind on an independent organoid time-course (days 15–120; GSE168323): Spearman ρ = 0.91 (95% CI 0.71–0.96) on whole organoids, 0.84 on neurons only. Synaptic markers is the v0.1 marker set; it failed that same test (ρ = −0.16), so it is shown for description only and never drives the verdict. DA identity: midbrain floor-plate TFs + dopamine synthesis/handling. Fidelity subtracts non-midbrain (forebrain/hindbrain) identity. Stress: glycolysis and ER-stress programs typical of stressed organoid cells (Bhaduri 2020; Gruffi, Vértesy 2022). Hypoxia: HIF targets, with glycolytic enzymes excluded so hypoxia is not double-counted. All sets are non-overlapping and frozen before analysing the ISS data.

Scoring: within each sample, each program gene is ranked against background genes (genes in no program); a program's score is the mean of those ranks − 0.5. Ranking against background only means one program rising cannot drag the others down. Scores ignore library size and work on bulk RNA-seq and single-cell pseudobulk alike.

Verdict rules (pre-registered)

Promising maturation: age clock up (g ≥ 0.5), identity/fidelity not down, no stress program up. Mixed state: maturation up together with a stress/hypoxia program. Dysregulated: maturation up but DA identity or fidelity down (g ≤ −0.5). Insufficient evidence: no robust maturation increase. Every call also requires FDR q < 0.05 (within-stratum permutation test) and the same direction in every cell line; the Python package additionally requires a bootstrap CI excluding 0.
