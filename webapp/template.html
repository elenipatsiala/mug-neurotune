How it works

What each score means

Maturity panel ✓: two read-outs that each tracked culture age in three midbrain-organoid time courses from three labs. Age clock v0.3: 50 genes that rise and 50 that fall with age in fetal midbrain neurons in two independent fetal datasets (GSE192405, GSE76381); frozen before a held-out test, which it passed (ρ = 0.95); ρ = 0.74–0.99 across the three labs. Progenitor loss: decline of SOX2 + NES (ρ = 0.94–0.98). A maturation change is called only when both agree (the Python package adds a third read-out, fetal-correlation age). Synaptic markers (v0.1) and common markers such as NeuN, SYP, TH and MAP2 track neuron content, not age, so they never drive the verdict. DA identity: midbrain floor-plate TFs + dopamine synthesis/handling. Fidelity subtracts non-midbrain (forebrain/hindbrain) identity. Stress: glycolysis and ER-stress programs typical of stressed organoid cells (Bhaduri 2020; Gruffi, Vértesy 2022). Hypoxia: HIF targets, with glycolytic enzymes excluded so hypoxia is not double-counted. All sets are non-overlapping and frozen before analysing the ISS data.

Scoring: within each sample, each program gene is ranked against background genes (genes in no program); a program's score is the mean of those ranks − 0.5. Ranking against background only means one program rising cannot drag the others down. Scores ignore library size and work on bulk RNA-seq and single-cell pseudobulk alike.

Verdict rules (pre-registered)

Promising maturation: both maturity read-outs up (g ≥ 0.5), identity/fidelity not down, no stress program up. Mixed state: maturation up together with a stress/hypoxia program. Dysregulated: maturation up but DA identity or fidelity down (g ≤ −0.5). Insufficient evidence: no robust maturation increase. Every call also requires FDR q < 0.05 (within-stratum permutation test) and the same direction in every cell line; the Python package additionally requires a bootstrap CI excluding 0.
